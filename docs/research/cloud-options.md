# 云端方案调研：中文课堂长录音（78 分钟 · AAC 55.8 kbps · 双声道同源）

- 调研时间：2026-10-20（各价格以当日抓取的官方页面为准，日后可能调整）
- 目标素材：单文件 78 分钟（1.3 小时）、AAC 55.8 kbps、双声道但两路内容同源
- 核心问题：云端能不能把「非目标说话人」直接去掉、输出干净音轨？成本多少？有哪些坑？
- 规则：**所有价格都尽量打开官方定价页核实**；凡未能在官方页面读到的，明确标注「未核实/二手」。汇率按 **1 USD = 7.1 CNY** 折算（仅用于横向比较）。

---

## 0. 结论先行（TL;DR）

1. **没有「抑制/删除非目标说话人并输出干净音轨」的现成云 API。** 所有平台能做的只有「说话人分离（diarization）标注 + 按时间戳切掉/静音」或「对指定内容做 bleep 消音」，不会有云服务替你「只留下老师的音轨」。唯一接近的是 AssemblyAI 的 **Voice Focus**（实时流式，+$0.10/小时，作用是让模型只听到主说话人、抑制环境与其他声音），它**只影响喂给模型的音频，不导出干净音轨**，且仅流式支持（预录文件不可用）。
2. 中文长录音转写，**国内云当前单小时价格带约 0.29～3.3 元/小时**，最便宜的可用组合是：
   - **阿里云百炼 `paraformer-v2`：0.288 元/小时**（含说话人分离，按秒计费，模型页原价核实）
   - **阿里云通义听悟：0.6 元/小时**（含说话人分离、自动语种识别，新版接口核实）
   - **阿里云百炼 `fun-asr` / `qwen3-asr-flash-filetrans`：0.792 元/小时**（新一代大模型 ASR）
   - **腾讯云录音文件识别（大模型 2.0 版）：0.8 元/小时**（后付费，核实）
   - 传统「录音文件识别」接口反而更贵：阿里 ISI 2.50 元/小时、腾讯 1.75 元/小时。
3. **78 分钟单文件（1.3 h）成本几乎可以忽略**：最便宜方案 ¥0.37，最贵（海外 Whisper）约 ¥3.3；真正的成本量级只对 65 h / 1000 h 有意义。
4. **两个会直接翻倍计费的坑**（对本素材很关键）：
   - 阿里 ISI 规则：**16 kHz 多声道按「声道数 × 时长」计费**（8 kHz 双声道才按单声道）；
   - AssemblyAI / Deepgram 都**按声道数计费**，双声道 1 小时 = 2 个计费小时。
   - 因为本素材「双声道同源」，**上传前先 downmix 成单声道**可以省 50%。
5. 长音频限制：百炼文件转写单文件 **≤12 小时 / ≤2 GB**（开说话人分离建议 ≤2 小时）；腾讯录音文件识别**单文件 ≤5 小时**；78 分钟在两个限制之内，**不需要分片**，但 1000 小时批量时要做并发/队列。

## 3. 分平台明细

### 3.1 阿里云（两条线：百炼 Model Studio / 智能语音交互 ISI，外加通义听悟）

**A. 百炼 Model Studio（推荐优先看这条线）**

- 录音文件识别（非实时，HTTP）支持的模型与能力（[ASR 概览](https://help.aliyun.com/zh/model-studio/asr-model)）：
  - `qwen-audio-3.1-asr-flash-filetrans`：12 小时 / 2 GB 上限，支持热词、Prompt 上下文、**说话人分离**（官方建议开说话人分离时 ≤2 小时）；
  - `fun-asr`：同样 12 小时 / 2 GB，支持说话人分离；
  - `paraformer-v2`：录音文件识别，**支持说话人分离**；
  - `qwen3-asr-flash-filetrans`：12 小时 / 2 GB，支持情绪识别，说话人分离列为「不支持」；
  - `qwen-audio-3.1-asr-flash`：仅 5 分钟 / 2 GB（短音频，不适用本素材）。
  - 输入支持 `aac`/`m4a`/`mp3`/`wav`/`mp4` 等，任意采样率（服务端会重采样到 16 kHz）→ **78 分钟 AAC 可以直接上传，不用转码、不用分片**。
- 价格（华北2 北京，模型页原价）：`paraformer-v2` **0.00008 元/秒 = 0.288 元/小时**；`fun-asr`、`qwen3-asr-flash-filetrans` **0.00022 元/秒 = 0.792 元/小时**；`qwen-audio-3.1-asr-flash-filetrans` 按 Token 计费（输入 0.8 元/M、输出 2.7 元/M），**无法直接折算成元/小时，需用真实数据实测 token 率**。
- 新人免费额度：仅华北2（北京）有，有效期 90 天，各模型独立；ASR 模型需在控制台业务空间**逐一开通**后才可调用并消耗额度（[免费额度说明](https://help.aliyun.com/zh/model-studio/new-free-quota)）。按秒计费模型的免费额度官方未在模型页标出，检索到的二手资料称「约 36,000 秒 / 10 小时」（**二手，未核实**）。

**B. 智能语音交互 ISI（老接口，反而更贵）**

- 计费项：录音文件识别、极速版、闲时版**都按录音时长**计费；8 kHz 双声道按单声道计费、**16 kHz 多声道按 声道数×时长**（[计费项](https://help.aliyun.com/zh/isi/getting-started/pricing)）。
- 后付费单价（[计费方式](https://help.aliyun.com/zh/isi/getting-started/billing-10)）：录音文件识别 **2.50 元/小时**（0～299 h/日，最高档降到 1.00）；极速版 3.30（降到 1.30）；**闲时版 1.00**（0～1 万 h，5 万 h 以上 0.60）。
- 资源包：录音文件识别 40h/100 元（2.50/h）、1000h/1200 元（1.20/h）、20000h/20000 元（1.00/h）。
- 免费：新用户 3 个月免费试用（试用版）。
- 结论：同一个阿里云，**百炼的 0.288 元/小时已经把 ISI 的 2.50 元/小时按在地上**，除非你已经在用 ISI 的 Appkey/自学习模型，否则没必要走 ISI。

**C. 通义听悟（一体化产品，按「会议/课堂记录」定位）**

- 新版接口商用价：**音视频文件转写 0.60 元/小时，送说话人分离、自动语种识别**；实时会议转写 0.60 元/小时；大模型能力（章节速览、全文摘要、关键词、口语书面化等）**每项 0.064 元/小时，可叠加**；多模态 PPT 提取 0.64 元/小时；翻译 4 / 0.5 元/小时（[计费说明](https://help.aliyun.com/zh/tingwu/pricing-and-billing-rules)）。
- 免费：新开通 90 天试用，**每天免费上传 2 小时**（音频时长）。
- 注意：旧版接口贵得多（音视频文件记录 9.5 元/小时起），别走旧版。

## 4. 关键问题：有没有「抑制/删除非目标说话人、直接输出干净音轨」的云 API？

**结论：无现成产品。** 逐条核对如下：

| 候选能力 | 实际行为 | 是否输出干净音轨 |
| --- | --- | --- |
| 说话人分离 diarization（阿里/腾讯/火山/讯飞/AssemblyAI/Deepgram） | 输出「谁在什么时间说话」的标签与时间段，**不改变音频** | ❌ |
| AssemblyAI **Voice Focus**（+$0.10/h） | 官方描述「Hear the speaker, not the room. Isolate the primary speaker and suppress everything else.」——作用是**只让模型听到主说话人、抑制其他声音**；**仅 Universal-3.6 Pro Realtime 流式支持**，预录文件不可用 | ❌（不导出音频，只影响识别输入） |
| PII **音频消音** redaction（AssemblyAI +$0.05/h、Deepgram Redaction +$0.12/h） | 对检测到的敏感内容做 bleep/替换，针对 PII，不是「非目标说话人」 | ❌ |
| 会议/课堂一体化产品（通义听悟等） | 输出分角色文本、摘要，可导出，但**不给干净音轨** | ❌ |
| 本地 TSE / 目标说话人提取（如 MossFormer2、SepFormer、pyannote + 声纹选择） | 真正把目标说话人音轨分离出来 | ✅ 但这是**本地模型**，不是云 API（见 `docs/research/local-options.md`） |

**云端现实可行的替代做法**（效果 = 「切掉」而不是「分离出干净音轨」）：

1. 调 ASR + diarization，拿到「每一句 - 说话人 - 起止时间」；
2. 用声纹/LLM 判断哪一轨是「老师」；
3. 用 `ffmpeg` 按时间段把非目标说话人的区间做切除或静音（`aselect`/`volume=0`），拼接后得到「近似干净」的音轨。
4. 局限：非目标说话人与目标说话人**重叠（overlap）**时无法处理；切掉会造成语句断层、时间轴错位；对低码率 AAC 二次编码会进一步损伤音质。

因此如果业务目标是「成品干净音轨」，应当把 TSE/降噪放到**本地**（成本=算力，一次性），云端只做「转写 + 分离标注」拿到文本与时间戳。

## 6. 隐私与合规提示（课堂录音上传第三方）

1. **法律框架**：境内处理适用《个人信息保护法》《数据安全法》《生成式人工智能服务管理暂行办法》。
2. **声音属于可识别个人信息**：课堂录音含教师与学生声音，声纹可关联到具体个人；若用于身份识别/声纹比对，会触及**敏感个人信息**，需「单独同意 + 必要性说明」。若录音含**未成年人**（尤其 <14 岁），需取得监护人同意。
3. **必须做的事**：告知用途与保留期限、取得教师与学生（监护人）同意、最小化上传（只上传必要音频、downmix、去掉无关片段）、选择**不作模型训练**的接口/企业协议、约定数据保留与删除、留存处理记录。
4. **数据出境**：使用 AssemblyAI / Deepgram / OpenAI 属于向境外提供个人信息，需按《个人信息出境标准合同办法》/安全评估路径合规；国内课堂场景建议优先**境内云**（阿里/腾讯/火山/讯飞）。
5. **服务条款要点**：确认厂商是否将音频用于「服务改进/模型训练」、是否支持「不保留/短保留」、是否可签 DPA、数据存储地域。
6. **成本之外的隐性成本**：ASR 结果含学生姓名/班级等个人信息，需做脱敏与访问控制；批量 1000 小时要评估留存策略，不要长期存放原始音频。

## 7. 推荐

| 场景 | 推荐 | 理由 |
| --- | --- | --- |
| **首选（性价比 + 能力平衡）** | 阿里云百炼 `fun-asr`（0.792 元/h）或 `qwen3-asr-flash-filetrans` | 单文件 12 h/2 GB，**78 分钟可直接上传不分片**；自带标点、时间戳；`fun-asr` 支持说话人分离；比传统 ISI 便宜 3 倍以上 |

| **要一体化产物（转写+分角色+摘要）** | 通义听悟（0.60 元/h，大模型能力 0.064 元/h/项） | 直接产出课堂纪要，省自研 pipeline；免费额度每天 2 h |

| **必须「去除非目标说话人」** | ❌ 云 API 无解 → 本地 TSE/目标说话人提取 + 云端只买「转写」 | 云上只能 diarization + 切段；成品干净音轨需本地模型 |
