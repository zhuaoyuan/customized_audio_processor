# 交付说明：可打包功能与使用方式（v0.2.0 / P0–P10）

> 本文是给「拿到代码包的人」看的功能清单 + 上手路径。
> 更细的阶段记录见 [工程日志](工程日志.md)，环境/FAQ 见 [使用说明](使用说明.md)，
> 成本与性能推算见 [运行评估](运行评估.md)，全文成稿实测见
> [全文成稿_方案与实测](全文成稿_方案与实测.md)。

## 1. 这套工具是什么

把公开平台的**课程录音**（m4a/mp3/wav/mp4…）批量处理成：

1. **干净音频**：降噪 + 头尾/长静音裁剪 + 响度归一化（真峰值限幅）；
2. **可校对的带时间戳转写稿**：ASR 段表 + `transcript.md/srt/txt`；
3. **（可选）LLM 错字纠错**：同音字/专名修正，逐段可追溯；
4. **（可选）全文成稿**：整讲通读后整理成完整、通顺的书面讲稿 `manuscript.md`。

全部在本机 **CPU** 上跑，不需要 GPU / torch；另带本地 Web UI（只监听 `127.0.0.1`）。

## 2. 功能清单

| 能力 | 命令 / 入口 | 产物 | 说明 |
|---|---|---|---|
| 解码 / 输入修复 | `decode`；`run` 自动调用 | 16k/44.1k wav（中间态） | MP4 `stco` 损坏自动修复后重试 |
| 分析（VAD/电平/边界） | `analyze` | 段表、边界、电平统计 | Silero VAD + P56 语音电平 + 120 s 窗口字符率 |
| 降噪 / 裁剪 / 响度 | `render`（denoise→trim→loudness→encode） | `clean.m4a`、`edit.json` | 目标 ASL −20 dBFS、真峰值 ≤−1 dBTP、削波 0 |
| ASR 转写 | `transcribe` | `transcript.json/md/srt/txt` | SenseVoice int8，句级时间戳（clean 轴 + 原轴） |
| 说话人标注（可选） | `diarize`；`diar.mode=sampled/full` | 每段 `speaker` | 默认 `none`，不加载模型 |
| LLM 错字纠错（可选） | `correct` | `corrections.json`、更新段表 | 需 `DEEPSEEK_API_KEY`；只改同音字/专名，不润色 |
| **全文成稿（可选）** | **`compose`** | `manuscript.md/json`、`compose_card.json`、`compose_report.json` | 整讲课程档案 + 分块整理；独立命令，不进 `run` |
| 全链路编排 | `run` | 上述 8 件产物 | 断点续跑、失败隔离、磁盘水位、锁 |
| 批量 | `batch` | 每个 job 一套产物 | `--resume` 默认；`--limit` 抽检；`--force` 重跑 |
| 任务状态 / 重试 | `status`、`retry` | `out/jobs.db` | `status --watch` 每 2 s 刷新 |
| 本地 Web UI | `serve` / `start_web.bat` | 浏览器操作 | 扫描/上传 → 跑 → 播放 → 改字 → 下载 |
| 回归 / 验收 | `regress` | `work/regress/p8.json` | 6 文件真实产物断言（默认 `--reuse` 秒级） |
| 全文成稿批量 | `compose --all` | 每个 job 的 `manuscript.md` | 按讲计费，建议先 `--limit 3` |

## 3. 三种典型用法

### A. 只要干净音频 + 转写稿（最常用，无 API key）

```powershell
$env:PYTHONIOENCODING='utf-8'
work\venv\Scripts\python -m app.cli run "data\24_【复旦哲学系丁耘】 亚里士多德《形而上学》(01)_normal..m4a" --out out
```

产物：`out/<job_id>/clean.m4a`、`transcript.md/srt/txt`、`transcript.json`、`edit.json`、
`report.json`、`corrections.json`（空结构）。

### B. 再加一层「错字纠错」（有 key）

```powershell
$env:DEEPSEEK_API_KEY='sk-...'
work\venv\Scripts\python -m app.cli correct --all
work\venv\Scripts\python -m app.cli export --all --force
```

### C. 再加一层「全文成稿」（有 key，按讲计费）

```powershell
# 1) 先看分块方案（不调 API）
work\venv\Scripts\python -m app.cli compose <job_id> --dry-run

# 2) 真正成稿
work\venv\Scripts\python -m app.cli compose <job_id>

# 3) 批量抽检 / 全量
work\venv\Scripts\python -m app.cli compose --all --limit 3
work\venv\Scripts\python -m app.cli compose --all
```

### D. 图形界面

```powershell
start_web.bat        # 或 python -m app.cli serve --port 7860
```

浏览器打开 `http://127.0.0.1:7860`：扫描/上传 → 开始处理 → 播放 → 改字 → 下载 md/srt/txt。

## 4. 安装（新机器）

要求：Windows 10、Python 3.10、ffmpeg 7.x 在 PATH。

```powershell
py -3.10 -m venv work\venv
$env:PIP_CACHE_DIR = "$PWD\work\pip_cache"
work\venv\Scripts\python -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
work\venv\Scripts\python -m app.cli config check
```

模型不入代码包（体积大），按 `configs/default.yaml` 的 `paths` 放置：

| 用途 | 默认路径 |
|---|---|
| ASR（SenseVoice int8 + tokens） | `work/bench/models/sensevoice/` |
| 降噪（RNNoise） | `work/bench/models/rnnoise/sh.rnnn` |
| 说话人（可选） | `work/diar/models/` |

可用 `MODEL_DIR` 覆盖模型根目录。没有 API key 时 `correct` 自动降级、`compose` 会明确报错。

## 5. 产物清单（每个 job）

`out/<job_id>/` 固定 8 件：

| 文件 | 内容 |
|---|---|
| `clean.m4a` | 降噪 + 裁剪 + 响度归一后的成品音轨 |
| `transcript.json` | 段表（start/end/orig_start/orig_end/speaker/text_raw/text/flags） |
| `transcript.md` | 带时间戳的可读转写稿 |
| `transcript.srt` | 字幕（clean 轴） |
| `transcript.txt` | 纯文本 |
| `corrections.json` | 纠错明细（无 key 时为空结构） |
| `report.json` | 各阶段指标（decode/vad/levels/trim/denoise/loudness/asr/speakers/correct） |
| `edit.json` | 裁剪/增益编辑记录 |

跑过 `compose` 再增加 4 件：`manuscript.md`、`manuscript.json`、`compose_card.json`、
`compose_report.json`。

> **时间轴**：`clean.m4a` 是裁剪后的音频；`transcript.json` 的 `start/end` 与
> `manuscript.md` 的 `[mm:ss]` 都在 **clean 轴**，与 `clean.m4a` 对齐；原始视频时间查
> `transcript.json` 的 `orig_start/orig_end` 或 `manuscript.json` 每段的 `orig_time`。

## 6. 实测性能与成本（来自本机 6 文件真实产物 / 单讲实测）

- 6 文件输入 **9.601 h**，clean 后 **8.912 h**；全链路 **RTF 0.1282** →
  500 h（300 文件 × 100 min）约 **64.1 h**（未达 DoD ≤30 h，差距与优化见 `运行评估.md`）；
- 交付磁盘 **≈23 GB / 500 h**；ASL **−20.02 ~ −20.07 dBFS**、真峰值 **−1.3 ~ −5.1 dBTP**、
  削波 **0**、时间戳段起点 abs median **0.18 s / P90 0.47 s**；
- 纠错（真实 API）：**≈¥0.379/文件**（300 文件 ≈¥114）；
- 全文成稿：1 小时 43 分讲座 **¥0.576/讲（档案缓存热态；新讲冷启动约 ¥0.60）、串行 14.1 min**，31,151→21,145 字（68%）、
  105 段、18/18 块通过、0 回退；
- 测试：**476 passed**（`work\venv\Scripts\python -m pytest -q`）。

## 7. 打包边界（代码包包含 / 不包含）

打包命令（仓库根目录）：

```powershell
work\venv\Scripts\python -m app.tools.package_release
# → dist/audio_processer-v0.2.0-<yyyymmdd>.zip
# 实测：89 个文件、原始 5.61 MiB、压缩后 4.47 MiB
```

脚本按白名单收集，`.git/`、`data/`、`out/`、`work/`、模型、`set_key.ps1`、
`local.yaml`、`app/transcript.md` 都不会进包；`tests/test_package_release.py` 对此有断言。

**建议打包**：`app/`、`configs/`、`docs/`、`tests/`、`README.md`、`CHANGELOG.md`、
`requirements.txt`、`pytest.ini`、`start_web.bat`、`.gitignore`。

**不要打包**：

- `data/`（原始音频，体积大且可能涉版权）；
- `out/`（运行产物、`jobs.db`、上传文件）、`work/`（venv、模型、缓存、证据脚本）、`.git/`；
- `work/set_key.ps1`、`configs/local.yaml` 等含密钥/私有配置的文件；
- 模型文件（SenseVoice / RNNoise / 说话人），单独交付或按文档下载；
- `app/transcript.md`（用户手工放进去的样例稿，不属于代码）。

## 9. 已知限制（交付时请一并告知）

- 500 h 全量约 64 h，**未达 30 h 目标**；瓶颈与优化选项见 `docs/运行评估.md` §7。
- Web UI 只监听 `127.0.0.1`、无鉴权；不要暴露公网。
- 中文长路径（>260 字符）未验证；控制台需 UTF-8。
- 纠错/成稿依赖 DeepSeek API；成本、限流、输出稳定性受服务方影响。
- 全文成稿是「整理」不是逐字校对：可能略去极短无效碎片、加入轻微书面化措辞；
  引文、页码/Bekker 号、专名必须人工对照原音复核。
- 说话人为可选能力，默认关闭；开启后的准确率未做大样本评估。
