# 热词表（LLM 纠错，P5-T2）

本目录下的 `*.txt` 是**按课程/文件**维护的专名与术语表，供 `app/pipeline/correct.py`
拼进 LLM 的 user prompt（system prompt 固定，热词只出现在 user 段）。热词只用于提示模型
"这些词优先按此写法"，模型输出仍要过 diff/数字/书名号/句数校验。

## 查找规则（`load_hotwords`）

按顺序取**第一个存在且非空**的文件：

1. `<job_id>.txt` —— 精确匹配当前 job（推荐，最稳）；
2. 课程名匹配 —— 取每个 `*.txt` 的文件名主干，若它（不区分大小写）出现在
   `report.json.source` 的文件名/目录名或 `job_id` 中，取**匹配最长**的一个
   （例：`f24.txt`、`亚里士多德.txt`）；
3. `default.txt` —— 通用兜底。

目录 / 文件缺失、文件为空 → 返回空表，不报错、不阻塞流水线。

## 文件格式

- 一行一个词；`#` 之后为注释；空行忽略；
- 也允许用 `、` `，` `,` `；` `;` 或空白在同一行分隔多个词；
- 顺序无所谓，自动去重。

示例：

```text
# 24 亚里士多德《形而上学》
亚里士多德
形而上学
吴寿彭
李真
苗力田
耶格尔
陈康
安德罗尼科
物理学之后
潜能与现实
```

## 维护建议

- 由人工/首轮纠错结果沉淀：把 `corrections.json` 里确认正确的专名修复补进来；
- 新课程先建 `<job_id>.txt`，稳定后可按课程名建一个 `fXX.txt` 复用；
- 不要把整段正文塞进来（只放专名/术语，否则会挤占上下文且降低前缀缓存收益）。
